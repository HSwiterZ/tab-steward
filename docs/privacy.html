Tab Steward

隐私政策

生效日期：2026-10-24 · 适用版本：1.0.0 及以后
中文English

一句话

Tab Steward 没有作者运营的服务器：不收集、不上报、不分析、不投放广告，也不出售任何数据。标签、书签、历史与设置都在你自己的浏览器里。

扩展会接触哪些数据

只在本机读取，用于界面展示与操作

  • 标签页、窗口与标签组：用于聚合、排序、切换、移动、休眠与关闭。
  • 书签与浏览历史：只在你使用统一搜索时读取，用于匹配结果，不会上传。
  • 最近关闭的标签：用于「最近关闭」列表与恢复。
  • 站点图标：通过浏览器（Chrome / Edge）自带的 _favicon 接口显示，不经过作者服务器。

保存在本机的数据

  • 收藏区、快照、使用统计、提醒、回收站与全部设置保存在 chrome.storage.local。
  • 可选「标签悬停截图」开启后，截图同样只保存在本机。
  • 卸载扩展或清除扩展数据会删除这些内容；设置页提供 JSON 备份与导入。

可选的 LLM 整理助手

该功能默认关闭，只有你自己填写服务地址与 API Key 并主动使用后才会发请求。请求直接发往你填写的地址，不经过作者。

  • 请求内容仅含标签标题、域名、闲置分钟数与状态，不含完整网址、书签或浏览历史。
  • Base URL 与 API Key 只保存在本机，由你随时修改或清空。
  • 该地址对应的服务如何存储与使用请求，取决于该服务的隐私政策。

网络请求与共享

  • 除可选的 LLM 助手外，扩展不向任何外部服务发送数据。
  • 不接入统计、崩溃上报、广告或社交 SDK。
  • 不向第三方出售、出租或共享数据，也不将数据用于广告、信用评估或借贷。

权限与用途

  • tabs / tabGroups：列出、切换、移动、休眠与关闭标签，管理标签组。
  • storage / unlimitedStorage：保存收藏区、快照、统计、提醒与设置；快照与截图可能超过默认配额。
  • bookmarks / history：把书签与历史纳入统一搜索，只读。
  • sessions：展示并恢复最近关闭的标签。
  • notifications / alarms：提醒与重复标签提示。
  • contextMenus：右键菜单里的标签操作。
  • favicon：显示站点图标。
  • <all_urls>（可选）：仅在开启「标签悬停截图」时申请，用于截取当前可见标签，可随时在设置页撤销。

有限使用承诺

扩展对上述数据的使用仅限于提供标签管理这一单一用途。不会将数据用于个性化广告、信用、借贷或保险评估，不会出售数据，也不会允许人工读取，除非出于安全、法律合规或你明确请求的必要范围。

儿童、变更与联系

本扩展不是面向儿童的产品，也不会主动收集儿童的个人信息。

若数据处理方式发生实质变化，会更新本页并修改生效日期。

Tab Steward

Privacy Policy

Effective 2026-10-24 · Applies to version 1.0.0 and later

In one sentence

Tab Steward has no developer-operated server. It does not collect, report, analyze, advertise, or sell data. Your tabs, bookmarks, history and settings stay in your browser.

What the extension touches

Read locally to render and operate the UI

  • Tabs, windows and tab groups: to group, sort, switch, move, discard and close tabs.
  • Bookmarks and browsing history: read only when you use the unified search, to match results; never uploaded.
  • Recently closed tabs: to show and restore them.
  • Site icons: served by the browser's built-in _favicon endpoint (Chrome / Edge), not by the developer.

Stored on your device

  • Collections, snapshots, usage analytics, reminders, the trash and all settings live in chrome.storage.local.
  • If you enable the optional "tab hover screenshot", those images are also stored locally only.
  • Uninstalling the extension or clearing its data removes all of it. The settings page provides JSON backup and import.

Optional LLM organizer

This feature is off by default. It sends a request only after you enter a service URL and API key and use it. Requests go directly to the endpoint you configure, never through the developer.

  • A request contains tab titles, domains, idle minutes and state only — no full URLs, bookmarks or browsing history.
  • The base URL and API key are stored locally and can be changed or cleared at any time.
  • How that endpoint stores or uses the request is governed by that service's own privacy policy.

Network requests and sharing

  • Apart from the optional LLM organizer, the extension sends no data to any external service.
  • No analytics, crash reporting, advertising or social SDKs.
  • No sale, rental or sharing of data with third parties, and no use for advertising, credit or lending decisions.

Permissions and their purpose

  • tabs / tabGroups: list, switch, move, discard and close tabs; manage tab groups.
  • storage / unlimitedStorage: save collections, snapshots, analytics, reminders and settings; snapshots and screenshots can exceed the default quota.
  • bookmarks / history: include bookmarks and history in unified search, read-only.
  • sessions: show and restore recently closed tabs.
  • notifications / alarms: reminders and duplicate-tab notices.
  • contextMenus: tab actions in the page context menu.
  • favicon: show site icons.
  • <all_urls> (optional): requested only for "tab hover screenshot" to capture the visible tab; revocable in settings.

Limited Use

The extension uses this data solely to provide its single purpose: tab management. It does not use data for personalized advertising, credit, lending or insurance eligibility, does not sell data, and does not allow humans to read it except when necessary for security, legal compliance, or at your explicit request.

Children, changes and contact

This extension is not directed at children and does not knowingly collect children's personal information.

If data practices change materially, this page and its effective date will be updated.

Questions or data requests: github.com/HSwiterZ/tab-steward/issues.
